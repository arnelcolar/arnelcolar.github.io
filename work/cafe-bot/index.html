Case study · Google Apps Script

A café's sales, costs, and stock, run from a group chat.

Staff type orders into Telegram the way they'd say them out loud. The bot prices each item from a menu sheet, logs it to Google Sheets, deducts stock, and replies with a total. A photo of a supplier receipt becomes an itemized expense.

How it works

Everything runs inside Google's free Apps Script runtime. The café already used Sheets and Telegram, so nobody had to learn a new app.

  1. PollA time trigger runs every minute and checks Telegram for new messages every ten seconds, saving its place in Script Properties so nothing is logged twice.
  2. ParseA message splits on commas and new lines. Each piece is read as quantity, item, and size, then priced from the Menu sheet.
  3. LogSales, expenses, and inventory live in separate tabs. Each sale deducts ingredients and warns when something drops below its minimum.
  4. Read receiptsPhotos go to a vision model that returns JSON. Personal items are dropped, and shop supplies are logged and restocked.

Keys stay out of the code

The bot token, API key, and sheet ID live in Script Properties. The code can be shared or pasted into a chat without handing over access.

var PROPS = PropertiesService.getScriptProperties();
var TOKEN = PROPS.getProperty("TELEGRAM_TOKEN");
var SHEET_ID = PROPS.getProperty("SHEET_ID");
var OPENROUTER_API_KEY = PROPS.getProperty("OPENROUTER_API_KEY");

Reading an order

One regular expression turns "2 kani-mango s" into a quantity, an item, and a size. When the size is left off, it defaults to 16.

function parseOrder(text) {
  var lower = text.toLowerCase().trim();
  var match = lower.match(/^(\d+)\s+(.+?)(?:\s+(\S+))?$/);
  if (!match) {
    return { error: 'Format: "1 latte 16" or "2 kani-mango s"' };
  }
  return {
    qty: parseInt(match[1], 10),
    item: match[2].trim(),
    size: match[3] || "16",
    error: null
  };
}

Trusting the model, carefully

Models sometimes wrap JSON in prose or code fences. The bot cuts out the first object it finds before parsing, and retries up to three times when the API errors.
