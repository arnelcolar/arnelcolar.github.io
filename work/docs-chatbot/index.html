Case study · AI support chatbot

A support chatbot that answers only from your own documents.

Give it a PDF, such as a product manual or a policy handbook. It answers from that file, cites the page, and shows the page when a diagram explains it better. If the answer isn't in the document, it says so instead of guessing. I built and tested it on a 1,379-page scanned car service manual.

How it works

01 / 04

A small Python server and one HTML page. Pointing it at a different document takes a new PDF, a new title and set of suggested questions, and one line in the prompt.

  1. IndexThe server splits the PDF into passages (2,389 for the manual) and turns them into vectors with a small open model. It builds the index once, in about five minutes for 1,379 pages, and loads it in about ten seconds after that.
  2. RetrieveEach question pulls the 20 closest passages. NVIDIA's reranker reads them against the question and keeps the best five.
  3. AnswerDeepSeek gets only those five passages, each labelled with its page, plus a prompt that tells it to cite pages and refuse anything the passages don't cover.
  4. Show the pageFor diagram and how-to questions, the bot shows the scanned pages its answer cites. Refusals show no pictures.

Staying on the document

02 / 04

Four layers keep the bot on its source. I tried to break them with ten attack prompts.

  1. Relevance gateIf the reranker scores even the best passage below a cut-off, the bot refuses before the language model sees the question. Real manual questions scored −2.9 or higher and off-topic ones −4.5 or lower, so I set the cut at −4.0. It adds no cost, since the reranker runs on every question.
  2. Strict promptAnswer only from the passages, cite the page, ignore any request to change the rules, and use one fixed refusal sentence.
  3. BlocklistThe bot refuses 95 known injection phrases on sight, such as "ignore previous", "developer mode", and "pretend you are".
  4. Safe outputThe page renders answers as Markdown and cleans them with DOMPurify first. Questions stop at 1,000 characters, and the page loads no outside scripts or fonts.

What broke, and the fix

03 / 04

I hit each of these while testing on the real manual.

  1. "Sorry," with a picture attachedThe model only reads text, so it refused diagram requests while the image code showed pictures anyway. Now each passage carries its page number, the prompt tells the model the app will show the page, and the app shows images only for pages the answer cites.
  2. Blank answersDeepSeek thinks before it answers, and it used up the default 1,024-token limit before writing a word. With thinking turned off, one procedure answer went from 201 seconds to 43.
  3. A retired endpointNVIDIA shut down the first reranker model on 25 August 2026. I switched models and added a fallback, so the next retirement changes the search order instead of breaking the chat.
  4. Scanned textOCR adds typos. The prompt tells the model to read past them but copy specs and part numbers exactly. I also took "emergency" off the blocklist, because it blocked "emergency brake" questions.

Selected code

Three excerpts. The server reads the API key from an environment variable, so you can share the code without handing over access. The full source stays private.

Refuse before asking the model

The reranker's score for the best passage decides whether the question is about the document at all. Off-topic questions never reach the language model.

MIN_RELEVANCE = -4.0

retrieved_docs = qa_chain.retriever.invoke(question.query)
top_score = retrieved_docs[0].metadata.get("relevance_score") if retrieved_docs else None
if not retrieved_docs or (top_score is not None and top_score < MIN_RELEVANCE):
    return {"answer": REFUSAL, "images": []}

Show only the pages it cites

The bot reads page numbers out of the answer ("page 92", "pages 90 and 95") and keeps only the ones it retrieved, so a made-up page number can't pull in a random image.

cited = {int(n) - 1
         for m in re.finditer(r"pages?\s+([\d,\s and&–-]+)", answer, re.I)
         for n in re.findall(r"\d+", m.group(1))}
pages = (cited & retrieved_pages) or retrieved_pages
refused = REFUSAL.lower().rstrip(".") in answer.lower()
images = extract_images(pages) if (intent_has_visual or context_has_phrase) and not refused else []

When the reranker fails

NVIDIA retires hosted models. If the reranker call fails, the bot keeps the top five search hits and carries on.

class SafeRerank(BaseDocumentCompressor):
    def compress_documents(self, documents, query, callbacks=None):
        try:
            return reranker.compress_documents(documents, query)
        except Exception as e:
            print(f"Reranker unavailable, using plain search order: {e}")
            return list(documents)[:5]
